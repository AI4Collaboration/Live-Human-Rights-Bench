# A benchmark instance and its evaluations

The manuscript uses Bouyid v. Belgium (001-157670, Article 3), its existing running example. The short case description is an editorial summary. All displayed scores and the static opinion are extracted from pinned saved runs. The model retains a violation judgment under all three input perturbations and reverses after the first low-pressure adversarial opinion.

Reproduce with `python analysis/case_walkthrough/extract.py` after the country-context audit. `example.json` retains source hashes and specifies the distinct reference arms and scoring protocols. No API calls are made.
